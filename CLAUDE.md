# Project
Equity Risk Dashboard for analyzing stock portfolios.

# Goals
- Build a professional, resume-quality application.
- Prioritize accurate financial calculations.
- Keep the interface clean and intuitive.

# Development Rules
- Follow the existing project architecture.
- Use clear, maintainable code.
- Avoid unnecessary dependencies.
- Never hardcode API keys.
- Write tests for financial calculations.
- Run relevant checks after making changes.
- Explain important architectural decisions.

# Workflow
- Plan major features before implementation.
- Make focused changes rather than broad rewrites.
- Avoid modifying unrelated files.
